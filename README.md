# המערכת האישית שלי

מערכת שעות אישית למדריכי טכני חיפה. האתר סורק את מערכת השעות של בית הספר
(https://techni.shahaf.site/) כל שעה עגולה בימי לימודים, 07:00–14:00, ובונה לכל מדריך דף אישי:
השיעור הנוכחי והבא, לפי יום, שבוע מלא, כיתות, תורני חצר, מבחנים ואירועים, ויומן שינויים.

כל מדריך נכנס לאתר ובוחר את השם שלו פעם אחת. הבחירה נשמרת במכשיר.

## החלקים
- **גיליון הניהול** (גוגל שיטס): אנשי צוות, צוותים (כולל עמודת "מפקד"), תוספות. כל הניהול היומיומי נעשה בו.
- `tracker/build.py`: סורק את שחף, קורא את הגיליון ובונה את `docs/data/`: דף לכל מדריך, כיתות, תורני חצר
  (`duty.json`), היסטוריית תורנויות (`duty_history.json`) ודוחות חודשיים (`duty_reports.json`).
- `tracker/push.py`: שולח התראות לטלפונים: סיכום בוקר, שינויים להיום, תזכורות ותורנויות בשעה הקרובה,
  סיכום צוות למפקדים, ודוח תורנויות בסוף החודש.
- `web/index.html`: האתר עצמו. GitHub Pages מפרסם את `docs/`.
- `apps-script/Code.gs`: **המנוע** (Google Apps Script בחשבון היחידה). שומר בגיליון פרטי את התזכורות,
  את הקישור של כל מדריך לטלפון שלו, את המנויים להתראות ואת השינויים הידניים בתורני חצר.
- `.github/workflows/update.yml`: העדכון השעתי. טיימר ב-cron-job.org מפעיל אותו.
  `check-api.yml` בודק שהמנוע עונה.

## תורני חצר
כל בוקר נבנית רשימה לכל שכבה: לכל שעה שהשכבה לומדת, מדריך פנוי אחד מהצוות שלה, ובהפסקה הגדולה
שני תפקידים. כל שעה הולכת לפנוי שעשה הכי מעט תורנויות החודש (טבלת צדק). כל איש צוות (מהטלפון
המקושר אליו, רק בשכבות של הצוות שלו), וגם מפקדים ואנשי מנהלה (עם קוד), יכולים לשנות שורה ידנית עם
הערה, והעדכון השעתי שומר את השינוי.

## קודים
- מדריכים: בלי קוד. הטלפון מקושר כשמפעילים התראות.
- ראשי צוות ומפקדים: קוד משותף. באתר נשמרת רק "טביעה" שלו (`config.json`), והמנוע בודק אותו מול
  "קוד מפקדים" בגיליון הפרטי.
- אנשי מנהלה: קוד בגיליון הפרטי בלבד ("קוד אנשי מנהלה").

## סודות בגיטהאב
- `PUSH_TOKEN`: "מפתח התראות" מהגיליון הפרטי.
- `VAPID_PRIVATE_KEY`: החצי הפרטי של מפתח ההתראות. החצי הציבורי נמצא ב-`config.json`.

בלי שני הסודות האתר עובד כרגיל, אבל לא נשלחות התראות.

## הרצה ידנית
```
python3 tracker/build.py            # סריקה ובנייה
python3 tracker/build.py --offline  # בנייה מחדש בלי סריקה
```
