# המערכת האישית שלי

מערכת שעות אישית למדריכי טכני חיפה. האתר סורק את מערכת השעות של בית הספר
(https://techni.shahaf.site/) כמה פעמים ביום ובונה לכל מדריך דף אישי: השיעור הנוכחי והבא,
לפי יום, שבוע מלא, מבחנים ואירועים, שיעורים שלא מתקיימים, שעת הסיום של כיתת החינוך ויומן.

כל מדריך נכנס לאתר, בוחר את השם שלו פעם אחת, והבחירה נשמרת במכשיר.

## איך זה עובד
- `staff.json` — רשימת המדריכים (שם כמו באתר בית הספר, תפקידים, כיתת חינוך).
- `tracker/build.py` — סורק את האתר פעם אחת ובונה את הנתונים של כולם לתוך `docs/data/`.
- `web/index.html` — הדף עצמו.
- `.github/workflows/update.yml` — מריץ את הסריקה בימים א'–ה' בסביבות 06:45, 08:15, 10:15 ו-13:05.
- GitHub Pages מפרסם את התיקייה `docs/`.

## תוספות שלא מופיעות באתר (תגבורים וכו')
שורה בגיליון גוגל (הכתובת ב-`config.json` תחת `extras_csv_url`), או ב-`extras.json`:
שם המדריך, יום (א–ה) או תאריך חד-פעמי, שעות, נושא, ואם רוצים כיתה וחדר.

## התראות לטלפון (ntfy)
אם מוגדר ב-GitHub הסוד `NTFY_SALT`, כל מדריך מקבל ערוץ ntfy משלו: סיכום בוקר,
ובמשך היום התראה רק על שינוי שחל באותו יום.

## הרצה ידנית
```
python3 tracker/build.py            # סריקה ובנייה
python3 tracker/build.py --offline  # בנייה מחדש בלי סריקה
```
